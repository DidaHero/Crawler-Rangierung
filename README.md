# Rezeptwand – interaktive Stichwortanalyse

Probiere das Tool hier aus: https://didahero.github.io/Crawler-Rangierung/

Ein didaktisches Tool zum **enaktiven Nachvollziehen der Arbeit von Crawlern und Suchmaschinen**.

Die Arbeitsweise von Crawlern wird dabei bewusst **stark vereinfacht** dargestellt. Lernende markieren Begriffe auf verschiedenen Webseiten, ordnen Inhalte zu und erstellen daraus einen Index. Anschließend können Webseiten für einen Suchbegriff rangiert und unterschiedliche Reihenfolgen verglichen werden.

## Funktionen

- Begriffe auf Beispiel-Webseiten markieren
- Inhalte verschiedenen Stichwörtern zuordnen
- Häufigkeiten erfassen
- Einen einfachen Index erstellen
- Webseiten nach Suchbegriffen rangieren
- Unterschiedliche Rangfolgen vergleichen

## Didaktischer Einsatz

Das Tool eignet sich für das Thema **„Suchmaschinen verstehen“**.

Es unterstützt dabei, grundlegende Abläufe wie **Crawling, Indexierung und Rangierung** handelnd nachzuvollziehen. Die dargestellten Prozesse sind didaktisch reduziert und bilden die tatsächliche Arbeitsweise moderner Suchmaschinen nur grob ab.

## Verwendung

Die Datei `index.html` in einem aktuellen Webbrowser öffnen oder das Tool über GitHub Pages bereitstellen.

Es ist keine Installation erforderlich.
